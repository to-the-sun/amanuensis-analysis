## Implementation Details & "The Librosa Way"

To reach the target parity, the following logic must be replicated exactly:

### 1. Spectral Analysis
- **FFT:** Centered frames with `n_fft = 2048` and `hop_length = sr / 1000` (1ms).
- **Padding:** Use reflective padding (`'reflect'` in Numpy) when indexing the audio buffer for the STFT.
- **Power-to-dB:** Librosa's `power_to_db` uses $10 \log_{10}(S / ref)$. By default, `ref=np.max`. The result is typically clipped to a `top_db` range (default 80.0).

### 2. Onset Strength (`librosa.onset.onset_strength`)
The onset envelope is not just a raw spectral flux. The internal algorithm is:
1.  **Log-Compression:** Usually performed on the Mel spectrogram.
2.  **Reference Spectrum:** By default, Librosa calculates a reference spectrum by applying a local maximum filter along the frequency axis (`max_size` parameter).
3.  **Difference:** `flux[f, t] = max(0, S[f, t] - S[f, t-1])` (if `max_size=1`).
4.  **Aggregation:** Typically the mean across frequency bins in the band.
5.  **Alignment:** Librosa pads the final envelope and trims it to match the input frame count. Specifically, when `center=True`, there is a shift of `n_fft // (2 * hop_length)` frames.

### 3. Peak Detection (`scipy.signal.find_peaks`)
Replicating SciPy's peak picking requires:
- **Local Maximality:** `env[i] > env[i-1]` and `env[i] > env[i+1]`.
- **Topological Prominence:** Finding the "lowest contour" or "higher terrain" connecting a peak to a higher peak.
- **Priority Filtering:** When applying a distance constraint (e.g., 200ms), the algorithm must keep the peak with the highest magnitude in the conflicting window.
